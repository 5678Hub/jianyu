五、已知机制说明

  1. idx 命中：节点有 own row 注册到 pathKey → 显示本级 own row
  2. idx 空 + ancestorsLevels 有显示：L2 通类 row 存在 → 显示 fallback row
  3. idx 空 + ancestorsLevels 全空：L2 通类 row 不存在 → 不显示任何内容 (PDF 表达即空)
  4. L3+ 节点不显示 L1 通类 row：v82-fix82 决策 (避免机制层 row 扩散)
  5. L2 节点可显示 L1 通类 row：v82-fix82 决策 (如「蛋制品」显示 L1「蛋及蛋制品」row)
  6. 跨级段已撤回：v82-fix85 取消「同章节其他通类」+「同 L3 其他 L4 兄弟」段
