# 食品安全抽检风险查询工作台

**单页 HTML + 本地数据**，无后端、无依赖，手机可访问。

## 启动（本机 80 端口 · 局域网 + 花生壳公网）

**最简单**：双击 `start-jianyu.bat` → 自动弹 UAC 提权 → 自动绕过执行策略 → 启动 80 端口服务。

- 本机访问：<http://jianyu/> 或 <http://127.0.0.1/>
- 局域网（同 WiFi 同事）：<http://你的局域网IP/>（脚本启动时会打印）
- 公网（不同网络的朋友）：在花生壳创建映射，内网主机填 `127.0.0.1`、端口 `80`、协议 `HTTP`，朋友访问花生壳生成的域名即可

> ⚠️ 启动后**不要关闭那个黑色窗口**，关了服务就停了。
> ⚠️ 80 端口若被占用（IIS / Apache / 阿里云盘 / VMware 等），脚本会提示，关闭占用程序后重跑即可。

## 启动（仅本机开发预览）

```bash
cd C:\Users\10487\WorkBuddy\jianyu
python -m http.server 8000
```

浏览器打开 [http://localhost:8000](http://localhost:8000)

> ⚠️ 必须用 HTTP server 启动，**不能直接双击 index.html** —— 因为要 `fetch` 加载 `data/` 下的 JSON 文件，浏览器对 `file://` 协议有跨域限制。

> HTTP server 不允许访问父目录，所以工作台维护一份数据副本。需要时跑 `sync_data.bat` 同步。

## 核心能力

### 单界面融合查询（v2.5）

**所有元素同时可见，无步骤区分：**

```
┌─ 食品名：[_______]              ← 顶部常驻
├─ 类别（2026 实施细则）          ← 中部常驻
│  [过滤框]
│  [一 粮食加工品] [二 食用油...] [三 调味品] ...
│  ... 共 39 个类别卡片 ...
├─ 结果区                        ← 按需渲染
│  风险等级 + 不合格明细 + 附件 1
└─
```

**交互：**

- 食品名未输入时 → 类别卡片呈"待输入"灰态
- 食品名已输入 → 类别卡片激活，点击即查
- 点击类别但未输入食品名 → 弹 Toast「请先在上方输入食品名」
- 已选类别高亮（蓝色描边）
- 食品名变化 → 自动重新渲染（保留已选类别）

**核心特性：**

- ✅ **39 大类完整目录**（从 2026 实施细则 PDF 提取）
- ✅ **本期附件 1 无条件显示**（即食品无不合格记录也要知道国检抽什么）
- ✅ **风险等级评分**（高 / 中-高 / 中 / 低 / 未检出，按不合格明细聚合）
- ✅ **类别聚合风险**（参考该大类下所有历史不合格）
- ✅ **无 Tab、无步骤** —— 全部元素同时可见
